# LinkShift

Легкий десктоп-инструмент для безопасного переноса тяжелых папок, кэшей и игр на другой диск с помощью `mklink`. Переносит данные через `robocopy` (с правами доступа и атрибутами), ставит на месте исходной папки символическую ссылку (junction / symlink), а программы при этом «думают», что ничего не менялось.

Офлайн-утилита: без аналитики, серверов и телеметрии. Собрана на [Neutralinojs](https://neutralino.js.org) — исполняемый файл весит единицы мегабайт, интерфейс — чистый HTML/CSS/JS без фреймворков.

## Интерфейс

Четыре вкладки в стиле Windows 11 (Fluent/Mica: акриловые поверхности, скругления, светлая и тёмная темы с запоминанием выбора):

- **Перенос** — выбор папки (диалог, ручной ввод или Drag-and-Drop прямо в окно), целевой каталог на другом диске, выбор типа ссылки (junction/symlink), подтверждение и пошаговый прогресс-бар с процентами и байтами.
- **Сканер диска C** — кнопка «Найти тяжелые папки»: кэши Chrome/Edge/Yandex, Telegram Desktop, Discord, шейдеры NVIDIA/AMD/Steam и любые папки в `%LOCALAPPDATA%`/`%APPDATA%` тяжелее заданного порога. Таблица с чекбоксами, пометками «можно переносить / не переносить» и пакетным переносом выбранных папок.
- **Ссылки на диске** — все junction/symlink в выбранной папке (по умолчанию `%USERPROFILE%`), включая созданные вручную через `mklink` вне приложения: путь, цель, тип, пометка «внешняя» или «создано в LinkShift». Кнопка **«Вернуть как было»** работает и для внешних ссылок: удаляет ссылку и возвращает файлы с целевого диска (если цель недоступна — предлагает удалить только ссылку). Скрытые системные ссылки Windows и `C:\Windows` отфильтрованы.
- **История** — все созданные приложением ссылки; кнопка **«Вернуть как было»** удаляет ссылку (`rmdir`), возвращает файлы обратно на исходный диск и удаляет запись из истории.

Переключатель языка **RU/EN** работает без перезагрузки приложения.

## Ключевые возможности

- **Режим «Перенести и связать»** — безопасная транзакция: проверка места → переименование в `.bak` (проба замка) → копирование `robocopy` → `mklink` → проверка ссылки → удаление `.bak`. Ошибка на любом шаге откатывает всё в исходное состояние.
- **Защита от потери данных** — папка, занятая запущенной программой, определяется на шаге переименования: копирование даже не начинается.
- **Сканер игнорирует уже созданные ссылки** (атрибут `ReparsePoint`) — папку нельзя предложить к повторному переносу.
- **Вкладка «Ссылки на диске»** — инвентаризация всех ссылок (включая созданные вручную) с быстрым обходом дерева на C# без спуска в reparse points — junction-петли Windows исключены по построению; откат внешних ссылок той же транзакцией, что и для ссылок приложения (проверка места → удаление ссылки → `robocopy /MOVE` обратно → очистка пустой цели).
- **Проверка прав администратора** при запуске и перезапуск через UAC (`Start-Process -Verb RunAs`). Junction (`mklink /J`) работает и без админа; symlink (`/D`) требует прав — без них делается fallback на junction с предупреждением.
- **UTF-8 без сюрпризов** — все пути (кириллица, пробелы, `%ENV%`) передаются в PowerShell через Base64, вывод консоли принудительно в UTF-8 (`chcp 65001` + `[Console]::OutputEncoding`).
- **Локализация RU/EN** через JSON-словари.

## Как это работает

```
C:\Тяжелая папка  ── robocopy ──►  D:\LinkShift\Тяжелая папка   (реальные данные)
       │
       └─ mklink /J ──►  C:\Тяжелая папка  →  D:\LinkShift\Тяжелая папка
                         (junction: программы видят папку как раньше)
```

Транзакция и ее откат реализованы в `resources/js/symlinkManager.js`, сканер — в `resources/js/storageScanner.js`, вся работа с командной строкой Windows — в ASCII-only PowerShell-скриптах `resources/ps/*.ps1` (PowerShell 5.1 читает файлы без BOM в системной кодировке, поэтому все динамические данные приходят в скрипты через Base64).

## Требования

- Windows 10 / 11 (x64)
- [Node.js](https://nodejs.org) — только для разработки (CLI `neu`)
- Права администратора — опциональны, но рекомендуются (полные NTFS ACL через `/COPY:DATS` и `mklink /D`)

## Установка и запуск

### Готовая сборка

1. Скачайте архив для Windows со страницы [Releases](https://github.com/RVMXL/LinkShift/releases) (`linkshift-win_x64.zip`).
2. Распакуйте в любую папку и запустите `linkshift.exe`.
3. SmartScreen может предупредить о неизвестном издателе — «Подробнее» → «Выполнить в любом случае» (у приложения нет сертификата подписи).

### Из исходников

1. Установите CLI Neutralinojs:
   ```bash
   npm install -g @neutralinojs/neu
   ```
2. Скачайте бинарники и клиентскую библиотеку (по версии из `neutralino.config.json`):
   ```bash
   neu update
   ```
3. Запуск в режиме разработки:
   ```bash
   neu run
   ```
   или через npm-скрипты: `npm run deps` → `npm run start`.

## Сборка из исходников

```bash
neu update
neu build --release
```

Готовые артефакты появятся в `dist/linkshift/` (бинарники для Windows/Linux/macOS + `resources.neu`). Сборка Windows-релиза возможна на любой ОС.

## Безопасность и ограничения

- Перенос корней дисков, `C:\Windows` и `Program Files` запрещен на уровне валидации.
- Вложенные ссылки не копируются (`robocopy /XJ`) и не обходятся при замере размеров — ни данные, ни байты не дублируются через чужие junction.
- Удаление `.bak` выполняется в два прохода: сначала отрываются вложенные reparse points, только потом рекурсивное удаление — классическая ловушка `Remove-Item -Recurse` через junction исключена.
- Если часть файлов в `.bak` занята и не удалилась, транзакция считается успешной (ссылка уже работает), но `.bak` сохраняется и упоминается в предупреждении — данные продублированы до ручной проверки.
- robocopy завершается с кодами 0–7 — норма; 8 и выше — ошибка с полным откатом.
- Приложение не содержит телеметрии и не отправляет данные куда-либо; журнал ссылок хранится только локально.
